# Task Manager

Aplicación de gestión de tareas y recordatorios desarrollada con Python y FastAPI.

## Tecnologías

- Python 3.12
- FastAPI
- Uvicorn
- SQLite
- SQLAlchemy

## Ejecutar el proyecto

Activar el entorno virtual:

```bash
source .venv/bin/activate
```
Instalar dependencias

```bash
python -m pip install -r requirements.txt
```

Arrancar servidor

```bash
uvicorn main:app --reload
```
